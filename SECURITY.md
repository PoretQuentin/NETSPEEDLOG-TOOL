# Politique de sécurité — NETSPEEDLOG-TOOL

## Versions supportées

| Version | Supportée |
| ------- | --------- |
| master (latest) | ✅ |
| Versions antérieures | ❌ |

## Signaler une vulnérabilité

**Ne pas ouvrir d'issue publique pour les failles de sécurité.**

Si tu découvres une vulnérabilité de sécurité dans ce projet, merci de la signaler de manière responsable :

1. Rends-toi sur l'onglet **[Security](https://github.com/PoretQuentin/NETSPEEDLOG-TOOL/security)** du dépôt.
2. Clique sur **"Report a vulnerability"** pour soumettre un rapport privé via GitHub.

### Ce que tu peux inclure dans ton rapport

- Description de la vulnérabilité
- Étapes pour la reproduire
- Impact potentiel
- Suggestion de correctif (optionnel)

### Ce que tu peux attendre

- Une confirmation de réception dans les **7 jours**.
- Une évaluation de la sévérité et un plan d'action dans les **30 jours**.
- Ton crédit dans le changelog si tu le souhaites une fois le correctif publié.

---

## Remarques

Ce projet s'exécute entièrement en local sur Windows. Il n'y a pas de serveur distant, pas de transmission de données à des tiers, ni d'authentification utilisateur. Les risques de sécurité sont principalement liés à la configuration locale de PowerShell et aux permissions d'exécution de scripts.
